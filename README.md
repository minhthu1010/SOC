# SOC - Security Operations Center Demo

## Mô tả / Description

Đây là repository demo cho mục đích kiểm thử SOC (Security Operations Center), bao gồm các tệp mẫu phục vụ việc kiểm tra IOC (Indicators of Compromise) và FIM (File Integrity Monitoring).

This repository contains demo files for SOC testing purposes, including sample files for IOC (Indicators of Compromise) and FIM (File Integrity Monitoring) testing.
